What is Git?
- Git is a version control system. Now, this is a fancy word. What version control exactly means is, effectively tracking the changes in the code of the project we are working on. 
Example: If 3 people are working on a project, then they will be working on the same codebase. And obviosuly not on the same time. One cannot know what changes the other person has made in the code. Or if while working you messed up the code, you can always revert to the previous code when you are using Git. With Git, each person can track and see what changes have been made in the code. 

What is GitHub?
- GitHub is a platform where all the repositories are stored for the project you or the people are working on. If Git is the page, then GitHub is the book.
