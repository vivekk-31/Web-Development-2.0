What is the Basic Workflow of Git?
- It can be divided into three stages:

Working Directory
Staging area
Repository

Working Directory: The files which contain the files which you are working on. 
Staging area: You add the files which you want to add in the repository on GitHub for which you want to track them. The moment any file is added using "git add 'file'", it comes to this staging area. 
Repository: Once any file is commited, it comes to this repository. Once it is in repository, then it is in GitHub and then it is getting tracked.
